# Config and system info

System specific config files
for my window manager (*sway[fx]*), terminal emulator (*alacritty*),
display manager (*ly*), notification daemon (*mako*), status bar
(*waybar, i3status[not anymore]*), *eww widgets*,
text editors (*emacs* and *neovim*), and *zsh*.

It also includes my installed applications and cursor, icons and fonts.

```bash
git clone https://github.com/amhue/dotfiles.git
```

```bash
cd dotfiles
chmod +x setup.sh
./setup.sh
```
